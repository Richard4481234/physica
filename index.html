Physica

About Physica

Physica is a collection of interactive physics experiments — a work in progress, with new ones added as time allows. The goal is simple: to let you see the laws of physics in motion, instead of only reading them.

How it was made

Every experiment is built as a single web page that runs in the browser — no plugins, no sign-up, and it works on anything. Assembled with the help of AI, and checked by a human.
